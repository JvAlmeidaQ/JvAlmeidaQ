## 🏆 Projetos em Destaque

### 🎵 [TrackListD — Plataforma Social de Avaliação Musical](https://github.com/TrackListD)
*Desenvolvedor Backend & Líder Técnico de Integração*

API RESTful para uma plataforma de catalogação musical, desenvolvida com **Spring Boot 3+** e **MySQL 8.4** em ambiente conteinerizado.

**Principais Desafios e Entregas:**
- **Performance:** Resolução de problemas críticos de Consultas N+1 utilizando `JOIN FETCH` e otimização de memória RAM com agregações nativas (`COUNT`) no banco de dados.
- **Integração e Autenticação:** Criação de fluxo de provisionamento transacional via Firebase Auth com táticas inteligentes de fallback para restrições de banco.
- **DevOps e Contratos:** Padronização do ambiente local via **Docker Compose** e documentação *Contract-First* com **Swagger/OpenAPI**.
- **Liderança (Scrum):** Orquestração da equipe de 5 pessoas no GitHub Projects com GitFlow rígido e revisões de código.
